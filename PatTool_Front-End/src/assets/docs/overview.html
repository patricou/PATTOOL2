Qu'est-ce que PatTool ?

PatTool est une application web privée pour organiser des activités (sport, sorties, famille, voyages…) et partager photos, fichiers et discussions avec un cercle d'amis authentifié via Keycloak.

Activités

Liste, création et mur de photos. Visibilité, fichiers, diaporama.

Liens

Signets personnels et partagés. Administration réservée aux admins.

Organisation

Agenda, listes de tâches, notes (post-it avec photos).

Monde

Espace : ISS, astronomie, viseur, boussole. Terre : météo, GPS, carte, électricité.

Business

Devises, bourse, cryptos, Loto, EuroMillions, foncier, artisans.

Média

TV, radio, livres, Archive, webcams, YouTube, films, Telegram, montage, actualités, Wikipédia.

Maison

Domotique, réseau, sentinelle, caméras, proxies, scan sécurité.

Science

Calculatrice, CERN, chimie, atelier de code.

Outils

Horloge, amis, WhatsPat, application Android, PDF, tableur ODS, système, documentation.

Assistant IA

Panneau latéral : OpenAI, Claude, Gemini, Mistral. Recherche web, vision, images, historique, exports PDF et WhatsApp. Guide complet →

SOS et carte

Dans la barre, à côté du logo : alerte SOS (position, WhatsApp ou SMS) et carte centrée sur vous.

Rôles et accès

Keycloak attribue des rôles qui débloquent certaines fonctions :

RôleExemples
Utilisateur connectéActivités, amis, WhatsPat, assistant, mur de photos
FileSystemLiens photos sur disque serveur (PHOTOFROMFS)
IotMenu Maison : domotique, caméras, scan réseau
AdminAdministration liens, paramètres serveur, stats système

La visibilité des activités (public, privé, amis, groupe) est gérée par l'auteur, indépendamment des rôles admin.

Premiers pas

  1. Connectez-vous via Keycloak.
  2. Le mur de photos (/photos) s'affiche par défaut.
  3. Consultez vos activités dans Activités → Liste (/even).
  4. Ouvrez l'assistant (baguette à droite) pour poser une question.
  5. La barre du haut porte aussi SOS et le badge CARTE.
  6. Menu Outils : horloge, amis, WhatsPat, PDF, tableur ODS, téléversement, partage, documentation.

Technologies (résumé)

  • Frontend : Angular 21, Bootstrap 5, Capacitor 8 (mobile)
  • Backend : Spring Boot 3.3, Java 21, MongoDB
  • Temps réel : WebSocket/STOMP pour WhatsPat ; SSE pour le flux d'activités
  • Fichiers : GridFS et disque serveur (photos PHOTOFROMFS, rôle FileSystem)
Note : l'ancien chat Firebase a été remplacé par WhatsPat. Il n'est plus utilisé.

What is PatTool?

PatTool is a private web app to organize activities (sports, outings, family, travel…) and share photos, files and discussions with friends, authenticated via Keycloak.

Activities

List, create, and the photo wall. Visibility, files, slideshow.

Links

Personal and shared bookmarks. Administration is for admins.

Organization

Calendar, todo lists, sticky notes with photos.

World

Space: ISS, astronomy, sky finder, compass. Earth: weather, GPS, map, electricity.

Business

Currency, stocks, crypto, Loto, EuroMillions, land, trades.

Media

TV, radio, books, Archive, webcams, YouTube, films, Telegram, montage, news, Wikipedia.

Home

Automation, network, sentinel, cameras, proxies, security scan.

Science

Calculator, CERN, chemistry, code workshop.

Tools

Clock, friends, WhatsPat, Android app, PDF, ODS spreadsheet, system, documentation.

AI assistant

Side panel: OpenAI, Claude, Gemini, Mistral. Web search, vision, images, history, PDF and WhatsApp export. Full guide →

SOS and map

In the bar, next to the logo: SOS alert (position, WhatsApp or SMS) and a map centered on you.

Getting started

  1. Sign in via Keycloak.
  2. Photo wall (/photos) is the default home.
  3. Browse activities at /even.
  4. Open the assistant (wand button on the right).
  5. The top bar also has SOS and the MAP badge.
  6. Tools menu: clock, friends, WhatsPat, PDF, ODS spreadsheet, upload, share, documentation.

Technology (summary)

  • Frontend: Angular 21, Bootstrap 5, Capacitor 8 (mobile)
  • Backend: Spring Boot 3.3, Java 21, MongoDB
  • Real-time: WebSocket/STOMP (WhatsPat); SSE (activity stream)
  • Files: GridFS and server disk (PHOTOFROMFS, FileSystem role)
Note: legacy Firebase chat was replaced by WhatsPat.
