Actualités

Route : #/api/news

  • Flux multi-fournisseurs (quota, délai et pays documentés par source)
  • Filtres : pays, langue, catégorie, recherche texte
  • Bandeau défilant optionnel en haut de l'application (ticker)
  • Bouton Assistant sur chaque article → titre + Gemini 3.1 Pro + recherche web

Wikipédia

Route : #/api/wiki (menu Média)

  • Recherche libre via le proxy backend /api/external/wiki/search
  • Résumé, image et lien de l’article via /api/external/wiki/summary
  • Choix de la langue de l’encyclopédie (fr, en, de, es, it, ru, ja, zh, ar, he, el, hi)
